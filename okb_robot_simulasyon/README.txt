OKB Asistanı Simülasyon V3

Bu sürüm, sunum/demo için yeniden düzenlenmiştir.
Robot artık komuta göre gerçekten ilgili odaya gider:

- /mutfak  -> mutfaktaki ocak kontrol noktasına gider.
- /utu     -> odadaki ütü masasına gider.
- /salon   -> salondaki lamba kontrol noktasına gider.
- /foto    -> anlık fotoğraf işareti koyar.
- /dur     -> robotu durdurur.
- /reset   -> simülasyonu sıfırlar.

Yuvaya dönüşte robot yuvanın önüne gelir ve son adımda yavaşça geri yanaşır.

Çalıştırma:
1. ZIP dosyasını çıkar.
2. VS Code ile klasörü aç.
3. index.html dosyasını Live Server ile aç.
